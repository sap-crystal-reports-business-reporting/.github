## Troubleshooting Common Issues

Install issues? Install the matching database client and confirm the connection tests successfully.  
Performance problems? Use server-side filtering, avoid returning unnecessary columns, and cache lookup data.  
License/activation? Check that the runtime version matches the report file version.  
Compatibility? Recompile reports when upgrading to a new major version.  
Update failures? Verify that the report's database credentials have not expired before rerunning a schedule.
